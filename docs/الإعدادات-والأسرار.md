# الإعدادات والأسرار — أين تعيش ولماذا

## المشكلة التي حُلّت

كانت بيانات الاتصال في `‎/var/www/html/iptv/.env‎` — أي **داخل المجلد
الذي ترفع نسخته من ويندوز**. وهذا يجمع خطرين في موضع واحد:

| ما يحدث عند الرفع | النتيجة |
|---|---|
| يستبدل ملف الخادم بنسختك المحلية | تضيع كلمة مرور الإنتاج |
| يعيد الملكية إلى مستخدم الـFTP | لا يقرأه Apache |

وكلاهما ينتهي بنفس الرسالة: **«خطأ في الاتصال بقاعدة البيانات»** —
وهي تصف العَرَض لا السبب، فتُرسل البحث إلى MySQL بينما العلّة في مكان آخر.

---

## أين تعيش الأسرار الآن

```
/etc/shashety/env          ← خارج جذر الويب · لا يصله الرفع
```

للتثبيت مرّة واحدة:

```bash
sudo bash /var/www/html/iptv/install_env.sh
```

السكربت **يتحقّق من صحّة البيانات قبل أن يثبّتها**، ولا يسمح لنسخة
محلية بأن تدهس إعداداً عاملاً، ويُبقي نسخة احتياطية.

---

## ترتيب المصادر

يقرأ الكود من الأعلى أولويةً إلى الأدنى، والأعلى يُلغي ما دونه
**مفتاحاً بمفتاح** — فيمكن أن يحمل `/etc/shashety/env` كلمة المرور
وحدها بينما تبقى بقية الإعدادات في مكانها:

| # | المصدر | متى يُستعمل |
|---|---|---|
| 1 | `$_SERVER` / `$_ENV` | `SetEnv` في Apache |
| 2 | `$SHASHETY_ENV` | مسار مخصّص تختاره |
| 3 | `/etc/shashety/env` | **الموضع القياسي** |
| 4 | `<فوق جذر الويب>/.shashety-env` | استضافة مشتركة بلا `/etc` |
| 5 | `<المشروع>/.env` | القديم — يبقى ليعمل ما هو قائم |

---

## لا ارتداد صامت بعد اليوم

كانت `env('DB_PASS', '123456')` تعني أن غياب الإعداد يُنتج محاولة اتصال
محكومة بالفشل برسالة MySQL مضلّلة. الآن:

- **لا ملف إعدادات إطلاقاً** → يتوقّف التشغيل برسالة تهيئة واضحة.
- **ملف موجود ولا يُقرأ** → يُسجَّل في سجل الأخطاء باسم المستخدم الذي
  فشلت القراءة بهويته، مع الأمر الصحيح للإصلاح.
- **كلمة مرور فارغة عمداً** (ملف مقروء وفيه `DB_PASS=`) → يمضي بلا اعتراض،
  لأن هذا إعداد مشروع في بيئات التطوير.

التشخيص يظهر لمن يتصفّح من الشبكة المحلية أو `localhost` فقط — لا يرى
زائر من الإنترنت شيئاً من بنية خادمك.

---

## في مجلدك المحلي

| الملف | الحال |
|---|---|
| `.env` | **حُذف** — لم يعد موجوداً كي لا يُرفع |
| `.env.backup-local` | نسختك القديمة، محفوظة للرجوع · محجوبة عبر HTTP |
| `.env.example` | نموذج بلا أسرار — هذا وحده يُرفع |

## التحقّق على الخادم

```bash
# ما المصدر المقروء فعلاً؟
sudo -u www-data php -r 'require "/var/www/html/iptv/core/config.php";
  echo (defined("ENV_SOURCE")?ENV_SOURCE:"?"), "\n";'

# هل يقرأه خادم الويب؟
sudo -u www-data test -r /etc/shashety/env && echo "نعم" || echo "لا"
```

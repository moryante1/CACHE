# دليل النشر النهائي

## الترتيب

```bash
# ١) ارفع الملفات — واستثنِ ما في docs/ملفات-لا-ترفع.md
#    (أهمّها .env و storage/ و uploads/)

# ٢) وحّد كلمة مرور قاعدة البيانات في كل المشاريع
sudo bash /var/www/html/iptv/fix_db_password.sh

# ٣) هيّئ وسيط إعادة البثّ (اختياري — إن أردت إصلاح AC3 وMKV)
sudo bash /var/www/html/iptv/setup_restream.sh

# ٤) افحص الجاهزية
sudo bash /var/www/html/iptv/release_check.sh

# ٥) نظّف ما يجب حذفه
sudo bash /var/www/html/iptv/release_check.sh --fix

# ٦) أعد الفحص — يجب أن يخرج بلا أخطاء
sudo bash /var/www/html/iptv/release_check.sh
```

---

## ما يفعله `release_check.sh --fix`

| الإجراء | لماذا |
|---|---|
| يحذف `db_check` و`subs_check` و`gate_check` و`capacity_check` و`stream_audio_check` | أدوات تشخيص تكشف بنية النظام وحالة الجلسات وبيانات الاتصال |
| يعيد تسمية `setup.php` و`loader.php` و`fix_db.php` إلى `.disabled` | ملفات تثبيت تنشئ حسابات وتنفّذ SQL |
| ينقل `*.rar` و`*.sql` و`*.bak` إلى `_archive/` | أرشيفات في جذر الويب قابلة للتنزيل |
| يضبط ملكية `.env` إلى www-data بصلاحية 640 | لو بقي لـ root بصلاحية 600 لا يقرأه Apache فترتدّ الإعدادات إلى الافتراضي بصمت |
| يصلح صلاحيات `storage` و`uploads` و`cache` | |

**لا يحذف** `health.php` — احتفظ به إن كنت تراقب الخادم، واحذفه إن لم تكن.

## الأشياء التي لا يستطيع السكربت فعلها نيابةً عنك

**نقل `Xp/` خارج جذر الويب.** نسخة كاملة من المشروع داخل مجلد يخدمه
Apache. حتى مع `.htaccess` فهي سطح هجوم بلا فائدة:

```bash
sudo mv /var/www/html/iptv/Xp /root/backup_Xp
```

**تفعيل HTTPS.** بدونه تُرسَل كلمات مرور المشتركين نصاً صريحاً عبر الشبكة —
وأنت الآن تبيع اشتراكات، أي أن لديك بيانات دخول حقيقية تحميها:

```bash
sudo certbot --apache -d نطاقك.com
```

**تغيير كلمة مرور لوحة الإدارة** إن كانت ما تزال الافتراضية.

## بعد النشر — تحقّق يدوي

| ما تفحصه | كيف |
|---|---|
| الصفحة الرئيسية | افتحها في نافذة خفية |
| بوابة المشتركين | فعّل الحماية ثم افتح في نافذة خفية |
| إنشاء حساب + كوبون | أنشئ حساب تجربة وولّد كوبوناً وفعّله |
| انتهاء الاشتراك | من اللوحة: تمديد `−30` يوماً ثم افتح الموقع |
| قناة تعمل | الجزيرة مثلاً — يجب أن تعمل بلا وسيط |
| فيلم من المكتبة | يجب أن يعمل عبر الوسيط إن كان mkv/ac3 |
| النسخ الاحتياطي | من اللوحة ← النسخ الاحتياطي ← تصدير |

## المتابعة الدورية

```bash
# حالة إعادة البثّ
php /var/www/html/iptv/tools/restream_gc.php --status

# صحّة النظام
php /var/www/html/iptv/health.php   # أو من المتصفح

# مساحة القرص (الأفلام تتراكم)
du -sh /var/www/html/iptv/storage/vod
```

الصيانة التلقائية تعمل كل دقيقة عبر `cron.d/shashety-restream`:
تُنهي البثوث المهجورة، وتقلّم سجل دخول المشتركين الأقدم من ٩٠ يوماً
مرة يومياً.

## ⚠ ما يبقى خارج سيطرة الكود

**النطاق الترددي.** إن فعّلت الوسيط فكل مشاهد يسحب من خادمك لا من مزوّد
Xtream. ٥٠٠ مشاهد ≈ ٢٫٥ غيغابت/ثانية صادرة. راقب الاستهلاك في الأيام
الأولى — لا يحلّ هذا القيدَ معالجٌ أسرع ولا كود أفضل.

**ترميز الفيديو.** إن كان بعض محتواك `h265/HEVC` فالوسيط سيحتاج إعادة
ترميز كاملة، وتكلفتها ٥٠–١٠٠ ضعف تحويل الصوت. شغّل `--scan` لتعرف:

```bash
php /var/www/html/iptv/tools/restream_gc.php --scan 20
```

**عقود المزوّد.** إعادة بثّ محتوى Xtream إلى مشتركيك قد تخالف شروط
مزوّدك. هذه مسألة تعاقدية لا تقنية.

# ملفات يجب استثناؤها من الرفع

هذه ملفات **يولّدها الخادم** وتخصّه وحده. رفع نسخة من جهازك يدهسها، والأثر
لا يظهر في الملف الذي رفعته بل في مكان آخر تماماً — وهذا ما يجعل تشخيصه بطيئاً.

| الملف | ماذا يحدث إن رُفع |
|---|---|
| `.env` | تُدهس كلمة مرور قاعدة البيانات ومفاتيح `WS_SECRET` و`HEALTH_KEY` → «حدث خطأ في الاتصال بقاعدة البيانات» بعد كل رفع |
| `storage/.appkey` | يتغيّر مفتاح التطبيق → تسقط الجلسات ويفشل فكّ تشفير ما حُفظ به |
| `storage/logs/` | تُدهس سجلات الخادم بسجلات جهازك |
| `storage/.installed`<br>`storage/.setup_done`<br>`storage/.subs_schema_ok` | علامات حالة: قد تُخبر النظام أن شيئاً تمّ وهو لم يتمّ على هذا الخادم |
| `cache/` · `uploads/` | ملفات المستخدمين والكاش — قد تُحذف أو تُستبدل بنسخ قديمة |
| `*.bak.*` · `*.rar` · `Xp/` · `_backup_before_fix/` | نسخ احتياطية لا داعي لرفعها (وXp نسخة كاملة من المشروع، ٢٨ ميغابايت) |

---

## FileZilla

القائمة **عرض ← قواعد ترشيح الملفات ← جديد**، ثم أضف في «الملفات المستثناة»:

```
.env
.appkey
*.bak.*
*.log
*.rar
```

وفي «المجلدات المستثناة»:

```
Xp
_backup_before_fix
node_modules
storage
cache
uploads
```

---

## rsync

```bash
rsync -avz --delete \
  --exclude='.env' \
  --exclude='storage/' \
  --exclude='cache/' \
  --exclude='uploads/' \
  --exclude='Xp/' \
  --exclude='_backup_before_fix/' \
  --exclude='node_modules/' \
  --exclude='*.bak.*' \
  --exclude='*.rar' \
  ./ user@server:/var/www/html/iptv/
```

> `--delete` يحذف من الخادم ما ليس عندك. الاستثناءات أعلاه تحمي مجلدات
> المستخدمين منه — بدونها يمسح `uploads/` كل الفيديوهات المرفوعة.

## WinSCP

**خيارات ← التفضيلات ← النقل ← تحرير**، وفي «قناع الاستثناء»:

```
.env; .appkey; *.bak.*; *.log; *.rar; Xp/; _backup_before_fix/; storage/; cache/; uploads/
```

---

## إن رفعت `.env` بالخطأ

الخادم سيتوقف برسالة الاتصال بقاعدة البيانات. الإصلاح:

```bash
sudo bash /var/www/html/iptv/fix_db_password.sh 'كلمة_المرور_التي_في_env_المحلي'
```

تمرير الكلمة صراحةً يجعل الخادم يطابق نسختك المحلية، فلا يتكرر العطل عند
الرفع القادم.
